# **App Name**: MyOffers

## Core Features:

- Promoter Registration Portal: A dedicated registration interface (register.html) for promoters to input personal and business details including First Name, Family Name, Email, and Mobile.
- Offer Creation Suite: A comprehensive form (create_offer.html) for promoters to publish deals, allowing for title entry, image uploads, category selection, and inventory tracking.
- AI Description Tool: A generative AI tool that assists promoters in drafting persuasive deal descriptions based on basic service or product bullet points.
- Three-Column Discovery Grid: The main landing page (index.html) featuring a responsive three-column layout to display the latest deals with categories like Food, Auto, and Home.
- Detailed Interaction Page: A dedicated offer page (offer.html) displaying rich descriptions, pricing, and a quantity selector alongside promoter contact information.
- Dynamic PHP Data Layer: Preparation for MySQL database connectivity to handle persistent storage of promoter profiles and offer inventory for the system's second phase.

## Style Guidelines:

- Primary Brand Blue (#007BFF) for trust and professionalism, paired with a clean white background to mirror the Cobone marketplace aesthetic.
- Discount Highlight Color (#FF4D4D) used specifically for highlighting actual prices and discount percentages to draw user attention.
- Headlines use 'Poppins' for a modern, bold look, while body text uses 'Arial' or 'Inter' for maximum legibility in product descriptions.
- A structured three-column grid for the homepage to ensure uniform display of deal cards across different categories.
- Consistent Header and Footer inclusion across all pages, containing navigation, search boxes, and administrative links as per site requirements.
- Semantic icons for categories (Home, Food, Auto) and social media icons in the footer to enhance visual navigation.
- Subtle hover effects on deal cards and button transition states to improve interactive feedback for customers.
